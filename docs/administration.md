# Администрирование

Админ-панель доступна по `/admin/`. Для входа нужен пользователь с
`is_staff=True`; суперпользователь создается командой `createsuperuser`.

## Промокоды

В таблице промокодов доступны два list action:

- **Сгенерировать коды** — создает фоновую задачу с указанным количеством;
- **Импортировать XLSX** — загружает файл и запускает асинхронный импорт.

Импорт читает первый столбец без заголовка, остальные столбцы игнорирует.
Некорректные строки и дубликаты пропускаются и записываются в файл результата.
Максимальный размер задается `XLSX_MAX_UPLOAD_SIZE`.

Статусы генерации и импорта находятся в отдельных журналах. Одновременно может
выполняться только одна генерация кодов.

## Розыгрыши

Кнопка ручного запуска находится в таблице розыгрышей. В выборку попадают коды
от конца предыдущего завершенного периода до времени нажатия кнопки. Если
розыгрыш за дату уже завершен, повторный запуск не меняет победителей.

Автоматический запуск выполняется в 00:00 по Москве. Победители отображаются в
inline-блоке розыгрыша и в отдельной таблице.

## Отчеты

XLSX-отчет формируется асинхронно за выбранный период. Статус и ссылка на
скачивание появляются в журнале отчетов. Сгенерированные файлы хранятся по
умолчанию семь дней.

## Пользователи и аудит

Детальная страница пользователя показывает количество зарегистрированных
кодов, успешных, неудачных и заблокированных попыток, даты активности и победу.

Журнал аудита фиксирует запуск и результат административных фоновых операций.
По умолчанию записи старше 180 дней удаляются ежедневной задачей; срок задается
`AUDIT_LOG_RETENTION_DAYS`.
