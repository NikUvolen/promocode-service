# Архитектура

Проект организован вокруг Django-приложений `accounts`, `promo`, `draws` и
`core`. Представления и admin-классы координируют запросы, а бизнес-правила
вынесены в сервисные модули.

## Слои

### API и UI

- DRF ViewSet для авторизации, профиля и пользовательских настроек;
- DRF ViewSet для регистрации и списка промокодов;
- публичный ViewSet завершенных розыгрышей;
- React-приложение для пользовательских сценариев;
- Django Unfold для операций администратора.

### Application services

Сервисы выполняют регистрацию пользователя и промокода, восстановление пароля,
проведение розыгрыша, импорт XLSX, генерацию кодов, формирование отчетов и
отправку уведомлений. Views и Celery tasks передают им данные и преобразуют
результат в HTTP-ответ либо статус фоновой операции.

### Domain и данные

Основные модели:

- `User` и `Profile`;
- `PromoCode` и `PromoCodeAttempt`;
- `PromoCodeGeneration` и `PromoCodeImport`;
- `Draw`, `Winner` и `DrawReport`;
- `AuditLog`;
- blacklist-модели Simple JWT.

Критичные инварианты закреплены ограничениями PostgreSQL: уникальность кода,
согласованность регистрации кода, один розыгрыш на дату, один приз каждого типа
за розыгрыш и не более одной победы на пользователя.

### Infrastructure

- PostgreSQL хранит доменные данные и обеспечивает транзакционные блокировки.
- Redis разделен логическими базами для Celery broker, cache и task results.
- Celery Beat запускает периодические задачи в часовом поясе `Europe/Moscow`.
- SMTP используется для пользовательских и обязательных писем победителям.

## Конкурентность

Регистрация промокода и проведение розыгрыша выполняются в транзакциях.
Сервис розыгрыша берет межпроцессную блокировку, а уникальные ограничения
останавливают повторное назначение пользователя, промокода или приза даже при
конкурентных запросах.

## Структура каталогов

```text
app/apps/accounts/   пользователи, профиль, auth API и письма
app/apps/promo/      промокоды, попытки, импорт и генерация
app/apps/draws/      розыгрыши, победители и отчеты
app/apps/core/       аудит и общие фоновые задачи
app/config/          Django, Celery, URL и WSGI-конфигурация
frontend/src/        React-страницы, компоненты и API-клиент
```
