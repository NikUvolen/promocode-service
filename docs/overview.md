# Обзор проекта

Gear Drop проводит промоакцию для покупателей игровых устройств. Пользователь
регистрирует уникальный промокод и участвует в ближайшем розыгрыше, период
которого покрывает время регистрации кода.

## Пользовательский сценарий

1. Пользователь регистрируется по email и подтверждает адрес по ссылке.
2. После входа заполняет имя, фамилию, телефон и отчество либо отмечает его отсутствие.
3. Вводит восьмизначный код из заглавных латинских букв и цифр.
4. Просматривает зарегистрированные коды и их статусы в личном кабинете.
5. Проверяет результаты завершенных розыгрышей на публичной странице.

## Правила промокодов

- Формат: `^[A-Z0-9]{8}$`.
- Код должен заранее существовать в пуле и может быть зарегистрирован один раз.
- Незаполненный профиль блокирует регистрацию кода.
- Три неудачные попытки за минуту блокируют ввод на пять минут.
- Успешная регистрация может сопровождаться письмом, если пользователь не отключил его.

## Правила розыгрышей

- Каждый день разыгрываются сертификат Ozon на 3 000 рублей и AirPods.
- В выборку входят коды текущего периода между предыдущим завершенным розыгрышем и cutoff нового запуска.
- Один пользователь может выиграть только один раз за всю акцию.
- Для даты существует только один объект розыгрыша, а повторный запуск завершенного розыгрыша не меняет победителей.
- Победителю отправляется обязательное письмо; неотправленные письма повторяются фоновой задачей.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| React/Vite | Лендинг, авторизация, профиль и личный кабинет |
| Django/DRF | API, бизнес-правила и административный интерфейс |
| PostgreSQL | Пользователи, промокоды, попытки, розыгрыши и аудит |
| Redis | Кэш, брокер и результаты Celery |
| Celery | Письма, розыгрыши, импорт, генерация, отчеты и очистка |
| Nginx/Gunicorn | Production HTTP и выполнение Django-приложения |
